# EXP-050 — NFC SHOW command: EEPROM WRITE 1/2/3, LED until latch, then EPD

## Hypothesis

TWN4 Type-2 WRITE of `OVH`+n to user page `0x30` (I2C block `0x0C`) is readable after FD (EXP-049 ACKAB). LED blinks only during that I2C latch; then off so the reader can leave while CoG still refreshes. Three RLE planes fit in 32 kB.

## Firmware

`v0.10a_nfc_showcmd`. CoG = v0.4k/v0.4l. Page 0x30 only (not UID/config/lock).

## Result

# EXP-067 — CoG stays initialized during chunked NFC

## HYPOTÉZA

Po BEGIN `epd_init()` zůstane CoG napájený a připravený během 235 střídání RF/I²C. DATA chunky jdou postupně do command `0x10` a `0x13`. Částečná CoG RAM bez `0x12` nemění poslední obraz.

## VSTUPNÍ STAV

Persistentní SRAM_MIRROR. `v0.12b_nfc_epd`. EXP-066 protokol PASS. TWN4 nad anténou, RF ON/OFF přes API, GPIO20 jednou na přenos.

## JEDNA HLAVNÍ ZMĚNA

BEGIN volá známou init sekvenci z v0.10e. MCU I²C jen po `set_rf_off`.

## SKUTEČNÝ VÝSLEDEK

UART RF-idle (`captures/nfc/ov26_exp068_uart.bin` a `ov26_exp068b_uart.bin`):

```text
INIT=01
TRANSFER ER=00 GOT=0000
P10=01
P13=01
```

`P10=01` až po prvních DATE do roviny 0x10, `P13=01` po 5 624 B. Host mezitím 235 chunků / ~336 s. Žádný POR, žádný `RESET_CAUSE` mid-transfer. CoG nepádí během mailbox smyčky.

## KLASIFIKACE

**PASS** — CoG zůstane inicializovaný přes celý chunkovaný NFC přenos.

## DALŠÍ KROK

EXP-068: COMMIT → `0x12` + BUSY ready.

# EXP-038 — NFC-0 TWN4 UID / GET_VERSION

## Hypothesis

ELATEC TWN4 on `/dev/ttyACM0` sees the GU140 NTAG I²C Plus over ISO14443-A (UID + GET_VERSION `00 04 04 05 02 02 13 03`). Read-only. No EEPROM write.

## Setup

- TAG ON (GPIO17 `dl`), debug isolated (GPIO27/21 `dh`)
- TWN4 `/dev/ttyACM0` — never `/dev/ttyUSB0`
- `hw` already in `dialout`
- `python3 tools/nfc_gateway/cli.py --port /dev/ttyACM0 reader-info`
- `python3 tools/nfc_gateway/cli.py --port /dev/ttyACM0 --wait 8 probe`

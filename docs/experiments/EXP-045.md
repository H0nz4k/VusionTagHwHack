# EXP-045 — NFC-C FD + LED pair vs TWN4 field

## Hypothesis

P1_1 is NTAG FD (active low). With debugger isolated, P2_1+P2_2 blink the proven LED pair (RGB then white) while TWN4 HF field is present. Without field, LED stays off.

## Firmware

`v0.7a_nfc_fd_led`. No I2C. FD input only. LED only P2_1/P2_2. Runtime GPIO27+21 OFF.

Host: `ovh-nfc field-watch` on `/dev/ttyACM0`.

## UART baseline (no TWN4)

```text
EXP-045 v0.7a NFC-C FD LED
RESET_CAUSE=01
FD=01 FIELD=00
DONE
FD=01 FIELD=00 LED=00
```

Idle FD **HIGH**. LED off. **OVĚŘENO** as no-field behaviour.

## Field-watch 12 s (current bench geometry)

TWN4: `in_field: false`, hits 0. UART stayed `FD=01 FIELD=00 LED=00`. No UID — čtečka teď **není** v dosahu (NFC-0 dřív UID našla). A/B FD vs RF proto **INCONCLUSIVE**.

## Result

Firmware + `field-watch` ready. LED/FD coupling čeká na lidské přiblížení TWN4 k anténě.

LED: P2_1+P2_2 = RGB i bílá zároveň (EXP-019). Samostatná jen-bílá GPIO mapa není.

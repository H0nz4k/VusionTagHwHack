# EXP-061 — SRAM_MIRROR config E8 + RF WRITE 0x40

## HYPOTÉZA

Config `0xE8` `SRAM_MIRROR_ON_OFF=1` a `SRAM_MIRROR_BLOCK=0x40` namapuje SRAM do user pages. TWN4 WRITE `0x40`=`OVMB` se objeví na MCU I2C `0xF8`.

## VSTUPNÍ STAV

DEV, GPIO20 TWN4 parked. `v0.11e`. Debugger izolovaný.

## JEDNA HLAVNÍ ZMĚNA

RF WRITE `0xE8` (ne `0xFE`/`0xEC`/`0xF0`).

## OČEKÁVANÝ VÝSLEDEK

`e8_after` = `1B 00 40 48`. UART `SRAM 4F 56 4D 42`.

## SKUTEČNÝ VÝSLEDEK

Flash OK. TWN4 UID `04367F5A2D7280`, PWD_AUTH OK.

```text
e8_before 19 00 F8 48
e9_before 08 01 01 00   REG_LOCK=0x01
e8_want   1B 00 40 48
error     WRITE 0xE8 NAK 0x0
```

Payload `0x40` neběžel.

## KLASIFIKACE

**FAIL** — RF Type-2 WRITE config `0xE8` NAK. Config se nezměnil. NXP: `REG_LOCK` bit0 = RF lock na konfiguraci.

## ZÁVĚR

Stejně jako session `0xEC`, config z NFC WRITE `0xA2` nejde. User page `0x30` (SHOW) pořád jde. Mailbox z RF do SRAM touhle cestou ne.

## DALŠÍ KROK

I2C write config bloku `0x3A` (EEPROM-like, ne `0xFE`). `REG_LOCK` I2C bit je 0.

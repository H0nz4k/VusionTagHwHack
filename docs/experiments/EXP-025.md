# EXP-025 — Phase D SPI idle only

## Hypothesis

USART0 Alternative 1 lze po PWR ON + P2_0 H-L-H bezpečně nakonfigurovat (MOSI P0_3, SCLK P0_5, CS P0_1 HIGH) bez odeslání bytu, bez změny P0_2 DIR/SEL, bez MCU/UART stormu. P1_3 zůstane HIGH po wait.

## Firmware

`v0.4d_spi_idle` on `research/gu140`

`--nooverlay`. Žádný `U0DBUF`. Žádný `0x00`/`0x0E`. DC (P1_2) a P2SEL nedotčeny. P0_2 se neselectuje ani nediriguje. RE (U0CSR.6) záměrně 0 — žádný MISO.

## Exact HW state

DEV tag. Runtime: GPIO17 dl, GPIO27 dh, GPIO21 dh. End: idle.

## Build / flash

SDCC `build_one.sh v0.4d_spi_idle` (~3.7K). `cc-tool -t` CC2510, verify OK.

## Test procedure

Isolated POR 32 s. P0_0=0, P2_0 H-L-H, bounded wait P1_3 HIGH (max 8× delay_crude), dump PRE, SPI idle config, dump POST, heartbeat. No SPI byte.

## UART

1× `EXP-025`, 1× `DONE`. `captures/ov26_exp025_por.bin`

## Observations

- MCU: jeden banner, `RESET_CAUSE=01`, HB 00–17, žádný re-banner
- WAIT n=01: první sample po H-L-H ještě nebyl HIGH, po jednom delay `BUSY=1` (slučitelné s EXP-024)
- POST `P0SEL=28` = bity 3+5, bit 2 = 0
- POST `P0DIR=2B` = P0_0/1/3/5 výstup, **P0_2 DIR=0**
- `PERCFG=02` = USART1 Alt2 beze změny, U0CFG=0 Alt1
- `U0CSR=00` = SPI master, RE off, žádný TX_BYTE
- `U0GCR=31` `U0BAUD=00` = MSB first, mode 0, BAUD_E=17 (REFERENCE GL340)
- CS latch HIGH po celý POST i heartbeat
- P0 POST `D6`: bit0=0 (PWR ON), bit1=1 (CS), bit2=1 (input), bity 3+5 pod periférií

## Result

**PASS** — SPI candidate interface lze bezpečně nakonfigurovat.

To **není** fyzické ověření MOSI/SCLK na FPC. Mapování zůstává **REFERENCE**.

## OVĚŘENO

Isolated USART0 Alt1 idle (P0SEL 3+5, CS GPIO HIGH, P0_2 GPIO input), žádný byte, MCU/UART stabilní, P1_3 zůstává 1.

## REFERENCE

USART0 Alt1 MOSI=P0_3 SCLK=P0_5, CS bitbang P0_1 (GL340).

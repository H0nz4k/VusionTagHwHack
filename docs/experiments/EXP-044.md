# EXP-044 — NFC-B STOP+START before 0xAB

## Hypothesis

NTAG NACKs 0xAB because repeated start was malformed; STOP then START (current-address / two-transaction read) gets ACKAB=1.

## Firmware

`v0.6e_nfc_sess2`. One change vs v0.6d: `i2c_stop()` + pauses + `i2c_start()` before 0xAB.

## UART

Isolated flash garbage (CP2102). Recapture **PASS**:

```text
OpenVusion GU140 EXP-044 v0.6e NFC-B STOP
RESET_CAUSE=01
ACKAA=01 ACKFE=01 ACKAB=00
SESS FF FF FF FF FF FF FF FF
DONE
```

Same as EXP-043.

## Result

**FAIL** (session read). STOP+START did not change ACKAB. Do not retry the same NACK a third time.

## Next

New analysis before another I2C-read flash: slower SCL, explicit Sr while SCL is low, or check whether TWN4 residual RF asserts I2C lock. Do not enable PTHRU/SRAM until ACKAB=1.

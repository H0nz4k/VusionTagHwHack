# EXP-031 — B/W/R calibration image

## Hypothesis

S pevným B/W z EXP-030 a oficiálním 2.66" BWR demem je červená:

```text
WHITE = plane10 0, plane13 0
BLACK = plane10 1, plane13 0
RED   = plane10 0, plane13 1
```

Pervasive `image_266_296x152_BWR.c`: 8785 px s `(0,1)`, **0 px s `(1,1)`**. Small-panel KB (`0x13` = dummy 0x00) platí jen pro BW obraz na BWR panelu — EXP-030 to potvrdilo (žádná červená).

## Firmware

`v0.4j_bwr_cal` — klon v0.4i (init/SPI/DCDC/`0x12` beze změny). Jen generátor framebufferu.

37 B/řádek:

| col | region | p10 | p13 |
|---|---|---|---|
| 0–11 | BLACK | 0xFF | 0x00 |
| 12–24 | WHITE | 0x00 | 0x00 |
| 25–36 | RED | 0x00 | 0xFF |

Marker: prvních 16 řádků, col 0–15 = BLACK (vybíhá do bílé).

`v0.4i_stripes` neupravován.

## UART (`captures/ov26_exp031_por.bin`)

```text
RESET_CAUSE=01
INIT=01
N10=15F8 OK=01 BUSY=1
N13=15F8 OK=01 BUSY=1
DCDC=01 BUSY=1
REF=01 BUSY=0
DONE
HB 00..16 BUSY=0
HB 17..2B BUSY=1
```

Isolated. TAG OFF. Obraz drží.

## Result

**PASS UART.** Stejný refresh cyklus jako EXP-029/030.

**Lidský vizuál (`captures/ov26_exp031_visual.png`):** náznak červené (špinavá lososová/hnědá), **ne** sytá stock červená. Obraz = **diagonální stupňovité pruhy**, ne tři velké oblasti. Barvy se míchají po scanline.

**Závěr:** 37 B/řádek (296/8) nesedí na native stride. Pervasive 2.66" = 296 řádků × **19 B** (152/8). Špatný wrap míchá BLACK/WHITE/RED v jedné vizuální oblasti → kalná červená. Polarita 0x13 pravděpodobně žije (náznak červené), ale nejde ji hodnotit, dokud oblasti nebudou souvislé.

## Klasifikace

PASS flow. Vizuál **FAIL vůči třem oblastem**. Encoding RED zatím ne OVĚŘENO.

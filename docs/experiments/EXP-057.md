# EXP-057 — I2C read SRAM block 0xF8

## HYPOTÉZA

Stejná I²C Sr sekvence jako EXP-049 (EEPROM `0x01` → ACKAB=01) na adrese **`0xF8`** (NTAG SRAM) dá ACKAB=1. Session `0xFE` se neopakuje.

## VSTUPNÍ STAV

DEV TAG1, `ov26-relays.sh attach` (17+27, pak USB cyklus). `cc-tool -t`: unlocked CC2510. Debugger při UART recap izolovaný (`dbg-off` + `usb-off`). Firmware `v0.11a_nfc_sram`.

## JEDNA HLAVNÍ ZMĚNA

Word address `0x01` → `0xF8`. Žádný NTAG write, žádné EPD.

## OČEKÁVANÝ VÝSLEDEK

UART `EXP-057 v0.11a NFC-D SRAM`, `ACKAA=01 ACKF8=01 ACKAB=01`, 8 B SRAM (klidně 00).

## SKUTEČNÝ VÝSLEDEK

Flash verify OK. Isolated POR recap (`captures/nfc/ov26_exp057_por.bin`):

```text
OpenVusion GU140 EXP-057 v0.11a NFC-D SRAM
RESET_CAUSE=01
ACKAA=01 ACKF8=01 ACKAB=01
SRAM 00 00 00 00 00 00 00 00
HB 00
HB 01
HB 02
DONE
```

Jeden banner, `DONE`, bez opakovaného POR. SRAM klid = nuly (bez PTHRU / bez RF zápisu).

## KLASIFIKACE

**PASS** — I2C read SRAM `0xF8` + `0xAB` ACK. OVĚŘENO UART.

## ZÁVĚR

Session `0xFE`+`0xAB` NACK (EXP-043) není obecná neschopnost číst za word-address. SRAM je z I2C vidět i bez PTHRU (NXP). RF stránky `F0–FF` pořád potřebují PTHRU.

## DALŠÍ KROK

EXP-058: I2C zápis session NC_REG `PTHRU_ON_OFF=1` (write na `0xFE` už ACK v EXP-043). Pak TWN4 WRITE `0xF0` a MCU znovu čte `0xF8`.

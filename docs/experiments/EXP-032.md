# EXP-032 — B/W/R cal, native 19 bytes/row

## Hypothesis

Kalná červená a diagonály v EXP-031 byly ze špatného stride (37 B). Oficiální 2.66" = 296 × (152/8) = **19 B/řádek**. Stejné kódování na souvislých třetinách dá hodnotitelnou červenou.

## Firmware

`v0.4k_bwr_19` — klon v0.4j, jen `ROW_B=19`. Init/SPI/DCDC/`0x12` beze změny.

| col | region | p10 | p13 |
|---|---|---|---|
| 0–5 | BLACK | 0xFF | 0x00 |
| 6–12 | WHITE | 0x00 | 0x00 |
| 13–18 | RED | 0x00 | 0xFF |

Marker: prvních 32 řádků, col 0–8 = BLACK.

## UART (`captures/ov26_exp032_por.bin`)

```text
INIT=01 N10=N13=15F8 REF=01 BUSY=0
HB 00..16 BUSY=0  HB 17+ BUSY=1
```

Isolated. TAG OFF.

## Result

**PASS UART.** **OVĚŘENO vizuálně** (`captures/ov26_exp032_visual.png`).

- vlevo **BLACK**
- uprostřed **WHITE**
- vpravo **RED** (sytá)
- černý marker v bílé oblasti viditelný

## Klasifikace

PASS. Native stride 19 B/row. Pixel encoding **OVĚŘENO**:

```text
WHITE = plane10 0, plane13 0
BLACK = plane10 1, plane13 0
RED   = plane10 0, plane13 1
```

`v0.4k_bwr_19` = known-good BWR baseline. `milestone/display-bwr`.

# EXP-026 — Phase E command 0x00 + data 0x0E

## Hypothesis

Po PWR ON, P2_0 H-L-H a SPI idle lze odeslat Pervasive soft-reset pár `0x00` / `0x0E` (DC command pak data, CS pulse jako GL340). MCU a UART zůstanou stabilní. P1_3 se může krátce stáhnout do LOW a vrátit HIGH.

## Firmware

`v0.4e_cmd00` on `research/gu140`

`--nooverlay`. Bounded SPI TX wait. Žádný `0x12`, žádný framebuffer. P0_2 nedotčen. DC = P1_2 GPIO.

## Exact HW state

DEV tag. Runtime: GPIO17 dl, GPIO27 dh, GPIO21 dh. End: idle.

## Build / flash

SDCC `build_one.sh v0.4e_cmd00` (~4.6K). `cc-tool -t` CC2510, verify OK.

## Test procedure

Isolated POR 40 s. H-L-H, wait BUSY HIGH, SPI Alt1, PRECMD dump, `TX 00` (DC=0), `TX 0E` (DC=1), 12× BUSY sample, POST, heartbeat.

## UART

```text
OpenVusion GU140 EXP-026 v0.4e CMD
RESET_CAUSE=01
WAIT OK n=01 BUSY=1
PRECMD P0=D6 P0DIR=2B P0SEL=28 P1DIR=14 P1SEL=40
BUSY=1 CS=1 DC=1
TX0=01 BUSY=1
TX1=01 BUSY=1
S 00..0B BUSY=1 CS=1
SAW0=00 SAW1=01
POST same P0SEL/P0DIR, P0_2 SEL/DIR=0, CS=1
DONE
HB 00..13 BUSY=1 CS=1
```

1× `EXP-026`, 1× `DONE`. `captures/ov26_exp026_por.bin`

## Observations

- MCU: jeden banner, `RESET_CAUSE=01`, heartbeat, žádný storm
- SPI: oba byty dokončily TX_BYTE (`TX0=01` `TX1=01`)
- CS po přenosu HIGH, P0_2 beze změny
- P1_3 po commandu **zůstal 1** ve všech vzorcích (~200 ms i ihned po TX). Žádný pozorovaný LOW pulse

## Result

**PASS** (UART dokončil command, SPI TX OK, MCU stabilní)  
**INCONCLUSIVE** (CoG přijal `0x00`/`0x0E`: BUSY se nezměnil)

To neznamená, že pin není BUSY, ani že MOSI/SCLK/DC jsou špatně. Pulse mohl být kratší než vzorek, nebo CoG na tento pár nereaguje viditelně.

## OVĚŘENO

Isolated odeslání dvou SPI bytů (0x00 command, 0x0E data) s CS/DC bitbang, MCU/UART žije, P0_2 GPIO input.

## REFERENCE

GL340/Pervasive GU-small: `register_data_sm` začíná `00 0E` = soft reset. DC P1_2.

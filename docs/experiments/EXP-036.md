# EXP-036 — RF-C bounded RX/RSSI

## Hypothesis

SRX enters MARC RX, RSSI is not stuck at reset 0x80, SIDLE recovers, no RX overflow loop.

## Firmware

`v0.5c_rf_rxrssi`. Flattened. Extra `delay_tiny()` helper → UART garbage; removed. Four RSSI samples via `delay_crude`.

## UART (`captures/rf/ov26_exp036_por.bin`)

```text
CAL=01
RXENT=01 MARC=0D
RSSI 00=0D  01=0E  02=0D  03=0C   (MARC=0D RFIF=0C)
AFTER MARC=01 RFIF=00
HB MARC=01
DONE
```

RFIF 0x0C = CS+PQT (bits 3+2). **Not** RXOVF (bit 6).

RSSI_dec 0x0C–0x0E ≠ reset 0x80. 10 kBaud offset 74 dB → about −67 to −68 dBm (plausible noise; diagnostic only).

No packet claim.

## Result

**PASS** as RX diagnostic. Isolated. TAG OFF.

# EXP-030 — vertical B/W stripes + second refresh

## Hypothesis

Stejný CoG flow jako EXP-029 s **jinými** deterministickými daty (8px svislé pruhy) zopakuje BUSY 1→0→1. Tím se vyloučí náhodná změna panelu.

## Firmware

`v0.4i_stripes` — klon v0.4h. Pervasive KB: first frame 1=černá, 0=bílá. `0x10`: střídá `0x00`/`0xFF`, 37 B/řádek (296/8). `0x13`: samé `0x00`. Stream, žádný framebuffer v RAM.

## UART (`captures/ov26_exp030_por.bin`)

```text
RESET_CAUSE=01
INIT=01
N10=15F8 OK=01 BUSY=1
N13=15F8 OK=01 BUSY=1
DCDC=01 BUSY=1
REF=01 BUSY=0
DONE
HB 00..16 BUSY=0
HB 17..2B BUSY=1
```

Identický časový tvar jako EXP-029. Isolated. TAG OFF po capture.

## Result

**PASS UART.** **OVĚŘENO vizuálně** (lidská fotka `captures/ov26_exp030_visual.png`).

Celý aktivní panel je vlastní vysokokontrastní B/W pruhový obraz. Není to starý stock obsah. First-refresh GPIO sada (PWR/RESET/CS/DC/MOSI/SCLK/BUSY) jako celek řídí E2266JS0C2.

Firmware posílal 8px pruhy po 37 B/řádek (296/8). Na fotce s krátkou stranou (okénka) dole vypadají pruhy vodorovně — to sedí, pokud je osa 296 na fotce svisle.

## Klasifikace

PASS. Vlastní data → EPD → vlastní obraz. `milestone/epd-first-refresh` a `milestone/display-test-pattern` jsou vizuálně potvrzené.

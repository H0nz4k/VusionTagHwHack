# EXP-049 — I2C read EEPROM block 0x01 (not session 0xFE)

## Hypothesis

ACKAB=00 in EXP-043/044 is specific to session pointer `0xFE` (I2C read-only). The same Sr + `0xAB` after word address `0x01` (EEPROM) returns ACKAB=1 and non-FF data. That would let the TWN4 WRITE a variant byte into user memory and the MCU read it.

## Firmware

`v0.6f_nfc_eep`. One change vs v0.6d: `i2c_write(0x01)` instead of `0xFE`. No NTAG writes. No EPD.

## UART recapture — OVĚŘENO

Isolated flash garbage; recapture 115200:

```text
OpenVusion GU140 EXP-049 v0.6f NFC-B EEP
RESET_CAUSE=01
ACKAA=01 ACK01=01 ACKAB=01
EEP 03 1E D1 01 1A 55 04 6E
DONE
```

I2C **read** of EEPROM works. Session `0xFE`+`0xAB` FAIL was the session window, not a dead read path. SRAM/PTHRU still gated; user EEPROM is enough for a 1/2/3 command byte.

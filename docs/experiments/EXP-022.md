# EXP-022 — Phase 1 passive BUSY (P1_3)

## Hypothesis

S aktuálním isolation workflow (GPIO27 dh at runtime) je P1_3 čitelný jako high-Z input bez budění ostatních EPD pinů. Úroveň po POR je stabilní. To **neprokazuje**, že P1_3 = EPD_BUSY.

## Firmware commit

Firmware: `v0.4a_busy_passive` on `research/gu140` (this experiment commit).

## Exact HW state

- DEV tag only
- GPIO17 dl during capture (TAG ON)
- GPIO27 dh (RESET_N + DD + DC disconnected)
- GPIO21 dh (debugger USB off)
- After test: all idle (dh)

## GPIO/debug relay state

Flash: `ov26-relays.sh attach` (17/27/21 dl, USB after 3 V).
Runtime: 27 dh, 21 dh, 17 dl.
End: idle.

## Build

SDCC 4.2.0, `./build_one.sh v0.4a_busy_passive` on Pi.
Hex ~2.8K. First build (3.1K) had UART garbage — SDCC overlay (`uart_u16` + helper). Second build: locals only in `main`.

## Flash

`sudo cc-tool -v read -e -w` after `cc-tool -t` showed CC2510. Verify completed.

## Test procedure

1. TAG OFF 2 s
2. UART 115200 8N1, timeout 22 s
3. TAG ON (true POR, debugger isolated)
4. Capture banner + BUSY + ~20 heartbeats

## UART

```text
OpenVusion GU140 EXP-022 v0.4a BUSY
RESET_CAUSE=01
P0DIR=00 P1DIR=10 P2DIR=00
P0SEL=00 P1SEL=40 P2SEL=00 PERCFG=02
BUSY=0
HB 00 BUSY=0
...
HB 13 BUSY=0
```

1× `EXP-022`. Capture: `captures/ov26_exp022_por.bin`

## Observations

- MCU stable (~20 s, 20 HB, no re-banner)
- RESET_CAUSE=01 EXTERNAL_RESET_N (same family as isolated GPIO17 POR)
- P0DIR=00 → P0_0/1/2/3/5 not outputs
- P2DIR=00 → P2_0 not output
- P1DIR=10 → only uart1 flash-CS P1_4
- P1SEL=40 UART TX; PERCFG=02 USART1 alt2
- P1_3 = 0 at POR and unchanged

## Result

**PASS** (MCU + input read + isolation)  
**INCONCLUSIVE** (P1_3 == EPD_BUSY identity)

HIGH/LOW alone is not proof of BUSY. No EPD stimulus in this layer.

## OVĚŘENO

- Isolated POR + this firmware: one banner, UART heartbeat, P1_3 static 0
- No extra EPD DIR bits set
- Debugger disconnected at runtime

## REFERENCE

P1_3 = EPD_BUSY (GL340 + E2266JS0C2 FPC 9)

## HYPOTÉZA

P1_3 static 0 with panel unpowered / CoG not inited. Later PWR/RESET may change it.

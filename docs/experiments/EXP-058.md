# EXP-058 — I2C write PTHRU, poll SRAM; TWN4 WRITE 0xF0

## HYPOTÉZA

I2C zápis session `0xFE` NC_REG = `0x59` (`0x19 | PTHRU 0x40`) ACK. RF pak smí WRITE stránku `0xF0`; MCU v dalším čtení `0xF8` uvidí magii `OVMB`.

## VSTUPNÍ STAV

EXP-057 PASS. DEV TAG1, reconnect attach. Debugger při I²C izolovaný.

## JEDNA HLAVNÍ ZMĚNA

Po stejném SRAM read jako 057: I2C write NC_REG PTHRU=1. Bounded poll `0xF8` (8×). Host během okna WRITE `0xF0`/`0xF1`.

## OČEKÁVANÝ VÝSLEDEK

`PTHRU ACKAA=01 ACKFE=01 ACKNC=01`. Po TWN4: některý `SRAM 4F 56 4D 42 …` (`OVMB`).

## SKUTEČNÝ VÝSLEDEK

Flash verify OK. Isolated recap (`captures/nfc/ov26_exp058_por.bin`):


TWN4 `mbox`: `no_tag` (čtečka nebyla na tagu) — RF WRITE **neproběhl**. SRAM nuly proto nic neříkají o RF cestě.

## KLASIFIKACE

**FAIL** pro I2C data-byte NC_REG (ACKNC=00). Word `0xFE` dál ACK (jako EXP-043).  
**INCONCLUSIVE** pro RF mailbox (no_tag).

## ZÁVĚR

Adresa session se I2C zapisovat *dá* (ACKFE=01). Samotný NC_REG bajt `0x59` NTAG odmítl. PTHRU z MCU zatím není OVĚŘENO. Neopakovat I2C **read** `0xFE`/`0xAB`.

## DALŠÍ KROK

EXP-059: stejná sekvence, data-byte `0x19` (aktuální NC_REG bez PTHRU). ACKNC=01 → problém je bit PTHRU / hodnota `0x59`. ACKNC=00 → obecný NACK na session data.

# EXP-059 — I2C session data byte 0x19 (no PTHRU bit)

## HYPOTÉZA

ACKNC=00 v EXP-058 je kvůli hodnotě `0x59` (PTHRU). Stejný zápis s `0x19` (aktuální NC_REG) dá ACKNC=01.

## VSTUPNÍ STAV

EXP-058 FAIL ACKNC. DEV, attach, isolated recap. Bez TWN4.

## JEDNA HLAVNÍ ZMĚNA

Data-byte `0x59` → `0x19`.

## KLASIFIKACE

**FAIL** — session data-byte NACK i pro `0x19`. Není to specificky PTHRU bit.

## ZÁVĚR

Po word address `0xFE` NTAG na I2C **nebere payload** (stejný vzor jako EXP-043: ACKFE=01, další bajt NACK). EEPROM `0x01` a SRAM `0xF8` čtení dál ACK. Mailbox z MCU přes I2C write session/PTHRU touto Sr sekvencí **nejde**.

## DALŠÍ KROK

Neopakovat stejný I2C write na `0xFE`. Nová větev: PTHRU z RF (session stránky `0xEC`/`0xED`) + MCU jen čte `0xF8`. Nebo NXP I2C lock/timing analýza bez dalšího stejného flash.

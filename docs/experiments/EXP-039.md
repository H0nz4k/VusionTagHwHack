# EXP-039 — NFC-A I2C ACK (first image)

## Hypothesis

Bit-bang I2C on P0_4/P0_6, write address 0xAA, gets ACK. ACK0 without P1_0, ACK1 after P1_0 HIGH.

## Firmware

`v0.6a_nfc_ack`. Dual-pass. `--nooverlay`. Isolated flash.

## UART

**FAIL as capture** (later shown to be CP2102 framing after `cc-tool` USB cycle, not this image). 169 B high-bit garbage. Same signature as post-flash captures of known-good `v0.5c`.

Do not treat as I2C NACK. Image was superseded by `v0.6b` before a valid recapture.

## Result

**INCONCLUSIVE** (invalid UART capture). TAG OFF.

## Next

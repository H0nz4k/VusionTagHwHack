# EXP-023 — Phase 2 EPD_PWR only (P0_0)

## Hypothesis

P0_0 = EPD_PWR, active LOW (GL340). Přepnutí 1→0 napájí CoG bez RESET/SPI. MCU zůstane stabilní. P1_3 se může změnit.

## Firmware

`v0.4b_pwr_only` on `research/gu140`

## Exact HW state

DEV tag. Runtime: GPIO17 dl, GPIO27 dh, GPIO21 dh. End: idle.

## Build / flash

SDCC `build_one.sh v0.4b_pwr_only` (3.6K). `cc-tool -t` CC2510, verify OK.

## Test procedure

Isolated POR 28 s. Sequence: P0_0=1 (OFF) → P0_0=0 (ON) 6 samples → P0_0=1 (OFF) → heartbeat. No P2_0, no SPI, P0_2 untouched.

## UART

```text

RESET_CAUSE=01
P0DIR=01 P1DIR=10 P2DIR=00
STATE PWR_OFF P0_0=1 BUSY=0
STATE PWR_ON P0_0=0
S 00..05 BUSY=0
STATE PWR_OFF P0_0=1
BUSY=0
DONE
HB 00..11 BUSY=0
```

1× `EXP-023`, 1× `DONE`. `captures/ov26_exp023_por.bin`

## Observations

MCU žil celé ON i po OFF. P1_3 zůstal 0. Napětí na EPD rail nebylo měřeno (žádná sonda).

## Result

**PASS** (MCU + P0_0 drive + isolation)  
**INCONCLUSIVE** (active-low opravdu napájí CoG; P1_3 identita)

BUSY beze změny bez RESET je slučitelná s Pervasive (BUSY po resetu, ne po pouhém PWR).

## OVĚŘENO

P0_0 jako výstup, isolated, MCU nestormuje. BUSY zůstává 0 při P0_0=0 i 1.

## REFERENCE

P0_0 EPD_PWR active LOW (GL340 + Figure 5-1 power switch)

## HYPOTÉZA

CoG ještě nedriveuje BUSY, dokud neproběhne HW reset.

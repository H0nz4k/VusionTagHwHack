# EXP-047 — NFC field triggers EPD refresh

## Hypothesis

The same P1_1 FD pulse that blinks the LED can gate the **unmodified** v0.4k CoG refresh. Bringing TWN4 to the tag draws BLACK|WHITE|RED stripes (visible vs leftover OpenVusionHack).

## Firmware

`v0.8a_nfc_refresh`. Wait for FD=0 (poll+LED), then exact v0.4k init/SPI/0x04/0x12. One refresh per boot. Debugger isolated. No mailbox (0xAB still NACK).


# EXP-034 — RF-A radio reset dump

## Hypothesis

CC2510 radio XDATA/SFR reset values are readable over UART after a bounded boot. No TX.

## Firmware

`v0.5a_rf_dump`. Flattened `main.c` + clock + uart. `--nooverlay`. No `radio.rel`.

First flash with `dump8(const char *)` helper: UART garbage from byte 0 (known SDCC overlay signature). Flattened retry: PASS.

## UART (`captures/rf/ov26_exp034_por.bin`)

Isolated. One banner. `RESET_CAUSE=01`. `DONE`. HB MARC=01. No storm.

## Result
